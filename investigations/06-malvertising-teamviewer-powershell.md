# Forensic Investigation: Download from Fake Software Site (Malvertising & Abuse of RMM)

* **Reference Link:** [Malware Traffic Analysis - 2025-01-22 Scenario](https://malware-traffic-analysis.net/2025/01/22/index.html)
* **Environment:** Kali Linux
* **Primary Analysis Stack:** Tshark

---

## 1. Executive Summary

On January 22, 2025, an internal endpoint (`10.1.17.215`) was compromised via a deceptive malvertising scheme impersonating Google Authenticator.

The user browsed to a fraudulent download site (`google-authenticator.burleson-appliance[.]net`), retrieving a trojanized loader. Upon execution, secondary payloads were downloaded over unencrypted HTTP from `5.252.153[.]241`, including PowerShell scripts (`pas.ps1`, `29842.ps1`) and modified TeamViewer binaries. The threat actor established persistence by creating startup shortcuts and abused TeamViewer components to secure interactive remote access while maintaining Command and Control (C2) connections on non-standard ports. Profiling via Kerberos authentication and SAMR RPC calls confirmed the affected system as `DESKTOP-L8C5GSJ`, belonging to user `shutchenson` (Steve Hutchenson).

## 4. Analytical Phase Breakdown & Commands (tshark)

### Phase 1: Host Identification and Layer 2 Discovery

#### A. Scoping Local Subnet Activity
Identified anomalous outbound web sessions across the client subnet (`10.1.17.0/24`), excluding network infrastructure (`.1`, `.2`):
```bash
tshark -r 2025-01-22-traffic-analysis-exercise.pcap \
  -Y "ip.src >= 10.1.17.3 and ip.src <= 10.1.17.254 and (http.request or tls.handshake.type == 1)" \
  -T fields -e ip.src | sort | uniq -c | sort -nr

```

* **Result:** Isolated `10.1.17.215` as the sole client originating extensive outbound web requests.



#### B. Extracting the Hardware MAC Address

Retrieved the source Layer 2 address from frames generated by the victim IP:

```bash
tshark -r 2025-01-22-traffic-analysis-exercise.pcap -Y "ip.src == 10.1.17.215" -T fields -e eth.src | sort -u

```

* **Result:** Confirmed MAC address `00:00:b7:26:4a:74`.



---

### Phase 2: Active Directory Identity Resolution

#### A. Extracting the Hostname

Targeted Kerberos machine account authentication tickets ending in `$`:

```bash
tshark -r 2025-01-22-traffic-analysis-exercise.pcap \
  -Y 'ip.src == 10.1.17.215 and kerberos.CNameString contains "$"' \
  -T fields -e kerberos.CNameString | sort -u

```

* **Result:** Output returned `desktop-l8c5gsj$`, confirming the NetBIOS hostname as `DESKTOP-L8C5GSJ`.



#### B. Extracting Domain Username

Inverted the filter logic to capture user authentication principals:

```bash
tshark -r 2025-01-22-traffic-analysis-exercise.pcap \
  -Y 'ip.src == 10.1.17.215 and kerberos.CNameString and !(kerberos.CNameString contains "$")' \
  -T fields -e kerberos.CNameString | sort -u

```

* **Result:** Identified interactive username `shutchenson`.



#### C. Full Legal Name Extraction via SAMR

Parsed the `samr_UserInfo21` RPC structure from Domain Controller response packets:

```bash
tshark -r 2025-01-22-traffic-analysis-exercise.pcap \
  -Y 'samr.samr_UserInfo21.full_name' \
  -T fields -e samr.samr_UserInfo21.full_name | sort -u

```

* **Result:** Exposed the full user name: `Steve Hutchenson`.

### Phase 3: Initial Vector & Secondary Payloads Analysis

#### A. Tracing the Deceptive Download Site

Inspected DNS queries and TLS Server Name Indication (SNI) records:

```bash
# Locate relevant DNS queries
tshark -r 2025-01-22-traffic-analysis-exercise.pcap \
  -Y 'ip.src == 10.1.17.215 and dns.flags.response == 0 and dns.qry.name contains "google"' \
  -T fields -e dns.qry.name | sort -u

# Correlate TLS SNI to destination IP
tshark -r 2025-01-22-traffic-analysis-exercise.pcap \
  -Y 'tls.handshake.extensions_server_name contains "burleson-appliance.net"' \
  -T fields -e ip.dst | sort -u

```

* **Result:** Confirmed access to `google-authenticator.burleson-appliance[.]net` (hosted on `104.21.64.1`).



#### B. Extracting Secondary Stages & C2 Channels

Inspected outbound HTTP requests and TCP handshake behavior:

```bash
# Extract HTTP staging requests
tshark -r 2025-01-22-traffic-analysis-exercise.pcap \
  -Y 'ip.src == 10.1.17.215 and http.request' \
  -T fields -e ip.dst -e http.request.method -e http.request.uri -e http.host | sort -u

# Audit outbound TCP SYN connections
tshark -r 2025-01-22-traffic-analysis-exercise.pcap \
  -Y 'ip.src == 10.1.17.215 and tcp.flags.syn == 1 and tcp.flags.ack == 0' \
  -T fields -e ip.dst -e tcp.dstport | sort | uniq -c | sort -nr

```

* **Findings:**
1. Plain HTTP downloads from `5.252.153[.]241` retrieving `29842.ps1`, `pas.ps1`, and TeamViewer binaries, accompanied by execution status logs indicating persistence creation (`startup shortcut created`).


2. Recurring TCP SYN attempts to `45.125.66[.]32:2917` and `45.125.66[.]252:443`.
